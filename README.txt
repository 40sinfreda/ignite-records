Ignite Records — static site (fixed bugs + full Spotify discography)

HOW TO UPLOAD TO GITHUB PAGES (igniterecords26.com):
1. Download this entire "ignite-records" folder.
2. Replace the files in your GitHub Pages repo with these files
   (or copy index.html, artist.html, submit*.html, css/, js/, artists/, brand/, favicon.svg).
3. Commit and push — the site updates in a few minutes.
